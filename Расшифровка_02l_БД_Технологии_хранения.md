# Дополнение к расшифровке лекции №2

📖 **Колоночная аналитика в Yandex Cloud (40 секунд).** Для аналитических запросов часто нужны отдельные поля множества записей: хранение по столбцам позволяет читать нужные данные.
В результатах Yandex Cloud за 2025 год описан кластер ClickHouse внешнего заказчика объёмом 2,5 ПБ. Имя заказчика и ускорение запросов не опубликованы — их не следует додумывать.
Источник: https://yandex.cloud/ru/blog/financial-results-2025

📖 **Мои данные и модель данных (35 секунд).** Для расписания мне нужен поиск по датам и связь занятий с предметами — подходит реляционная модель. В плейлисте и заказе удобно объединять вложенные элементы и метаданные; заметки можно хранить документами с тегами.
Контакты можно рассматривать как граф, если нужна работа со связями между людьми. Эти модели я рассматриваю для своих задач с помощью ИИ; реальное устройство приложений может отличаться.
